Tema 13 · Modelação de dados

Do modelo conceptual ao modelo relacional

Transformação do modelo conceptual no modelo relacional: entidades, tabelas e atributos

O DER é um modelo conceptual. Para o implementar numa base de dados relacional, é preciso transformá-lo em tabelas. Existem regras simples para essa transformação.

Elemento do DERPassa a ser
EntidadeTabela, com o mesmo nome (normalmente).
Atributo simplesColuna da tabela.
Atributo compostoUma coluna por cada componente (rua, código postal, localidade).
Atributo derivadoNão se guarda; calcula-se quando necessário.
IdentificadorChave primária.
Relacionamento 1:NA chave primária do lado «1» passa para o lado «N» como chave estrangeira.
Relacionamento 1:1Chave estrangeira num dos lados (de preferência onde a participação é obrigatória).
Relacionamento N:MNova tabela, com as chaves primárias das duas entidades como chaves estrangeiras (e os atributos do relacionamento).

Notação textual

Costuma escrever-se o modelo relacional de forma compacta: o nome da tabela e, entre parênteses, as colunas, com a chave primária sublinhada e as chaves estrangeiras marcadas com #.

Turma(códigoTurma, ano, curso)
Aluno(nºAluno, nome, dataNascimento, #códigoTurma)
Disciplina(códigoDisciplina, designação, cargaHorária)
Inscrição(#nºAluno, #códigoDisciplina, nota)

A tabela Inscrição resolve o N:M entre Aluno e Disciplina. A sua chave primária é composta pelas duas chaves estrangeiras.

Atividade

Converter um DER num conjunto de tabelas relacionais

Converta o DER da biblioteca (tema 11) num conjunto de tabelas relacionais, escrevendo-as na notação textual, e apresente um exemplo de dados para duas das tabelas.

Ver proposta de resolução

Autor(idAutor, nome, nacionalidade)

Empréstimo(nºEmpréstimo, dataEmpréstimo, dataPrevistaDevolução, dataDevolução, #nºLeitor, #nºExemplar)

Em resumo

  • Cada entidade dá origem a uma tabela e cada atributo a uma coluna.
  • Nos relacionamentos 1:N, a chave primária do lado 1 passa para o lado N como chave estrangeira.
  • Os relacionamentos N:M dão origem a uma tabela associativa.
  • Os atributos derivados não se guardam.
