Tema 14 · Modelação de dados

Modelo físico: chaves primárias e candidatas

Modelo físico de dados; chaves primárias e chaves candidatas

O modelo físico descreve como as tabelas são realmente criadas num sistema de gestão de bases de dados (SGBD): tipos de dados, tamanhos, restrições, chaves e índices. Aqui, as chaves tornam-se concretas.

Tipos de chaves

ChaveDefiniçãoExemplo (Leitor)
CandidataConjunto mínimo de colunas que identifica cada linha de forma única.nºLeitor, NIF, email
PrimáriaA chave candidata escolhida como identificador oficial. Nunca pode ser vazia nem repetida.nºLeitor
AlternativaAs candidatas que não foram escolhidas; mantêm-se únicas.NIF, email
CompostaChave com mais de uma coluna.(ISBN, idAutor) na tabela Autoria
SubstitutaNúmero artificial criado só para identificar (por exemplo, automático).nºLeitor sequencial

Como escolher a chave primária

  • Deve ser única e nunca vazia.
  • Deve ser estável: não muda ao longo do tempo (o email pode mudar; o número de leitor não).
  • Deve ser curta e simples de usar.

Exemplo em SQL

CREATE TABLE Leitor (
  nºLeitor      INT          PRIMARY KEY,
  nome          VARCHAR(80)  NOT NULL,
  NIF           CHAR(9)      UNIQUE,
  email         VARCHAR(100) UNIQUE,
  dataInscrição DATE         NOT NULL
);

A chave primária implica NOT NULL e unicidade. As alternativas ficam protegidas com UNIQUE.

Atividade

Identificar chaves primárias e candidatas nas tabelas do projeto

Para cada tabela do projeto, identifique as chaves candidatas, escolha a chave primária e justifique.

  1. Leitor(nºLeitor, nome, NIF, email, telemóvel)
  2. Livro(ISBN, título, editora, anoEdição)
  3. Exemplar(nºExemplar, ISBN, cota, estado)
  4. Empréstimo(nºEmpréstimo, nºLeitor, nºExemplar, dataEmpréstimo)
  5. Autoria(ISBN, idAutor)
Ver proposta de resolução
TabelaChaves candidatasChave primáriaJustificação

LivroISBNISBNCódigo internacional único por edição.

EmpréstimonºEmpréstimo; (nºExemplar, dataEmpréstimo)nºEmpréstimoMais simples do que a chave composta.
Autoria(ISBN, idAutor)(ISBN, idAutor)Nenhuma coluna isolada identifica a linha.

Em resumo

  • O modelo físico concretiza tipos de dados, restrições e chaves.
  • Chaves candidatas identificam cada linha; uma é escolhida como primária.
  • A chave primária deve ser única, não nula, estável e curta.
  • As chaves alternativas protegem-se com restrições de unicidade.
